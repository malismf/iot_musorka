# Модели корпуса

Корпус описан кодом: `model/params.py` — размеры, `model/parts.py` — геометрия.
`python build.py` собирает по отдельному STL на каждую деталь в `stl/` и
чертежи в `render/`. Правится один файл параметров — пересобирается всё, и
чертёж расположения элементов не может разойтись с моделью.

```bash
cd cad
pip install -r requirements.txt
python build.py                 # STL + чертежи
python build.py --stl-only      # только печать
python build.py --render-only   # только картинки
```

Сборка занимает несколько секунд и не требует ни Fusion 360, ни FreeCAD.
STL открываются любым слайсером; при желании доработать формы руками —
импортируйте STL во FreeCAD или Blender, параметры останутся в коде.

## Детали

| Файл в `stl/` | Деталь | Материал | Как печатать |
|---|---|---|---|
| `body.stl` | основание | PETG / ASA | дном на стол, поддержки не нужны |
| `cover.stl` | крышка | PETG / ASA | плитой на стол, «ласточкин хвост» вверх |
| `gasket.stl` | уплотнитель | TPU 95A | плашмя; можно заменить резиновым шнуром 2.4 мм |
| `sensor_insert_a02yyuw.stl` | вставка под A02YYUW | PETG / ASA | юбкой на стол |
| `sensor_insert_hcsr04.stl` | вставка под HC-SR04 | PETG / ASA | юбкой на стол |
| `bracket.stl` | кронштейн на крышку контейнера | PETG / ASA | плитой на стол, пазом вверх |
| `button_cap.stl` | толкатель кнопки | TPU 95A | шляпкой на стол |
| `light_pipe.stl` | световод | прозрачный PETG | фланцем на стол |

Суммарно около 192 см³ пластика на устройство, из них 87 см³ — основание.
PLA не годится: на солнце крышку контейнера нагревает выше 60 °C, и деталь
ведёт.

`build.py` перед выгрузкой проверяет каждую деталь: замкнутая поверхность,
ненулевой объём, один кусок. Деталь, распавшаяся на два куска (например,
защёлка, потерявшая связь с консолью), до принтера не доедет, и ошибку лучше
увидеть в консоли, чем через три часа печати.

## Чертежи

| Файл в `render/` | Что показывает |
|---|---|
| `layout.svg` | схема расположения элементов, вид сверху со снятой крышкой, с размерами |
| `assembly_open.svg` | сборка со снятой крышкой, изометрия |
| `assembly_closed.svg` | устройство в сборе с кронштейном |
| `exploded.svg` | разнесённый вид с порядком сборки |

Это пункт 4 задания. SVG печатается в PDF из браузера или Inkscape.
Рендер свой, без внешних библиотек: ортографическая проекция с отсечением
нелицевых граней — картинки для записки и презентации он даёт, а зависимостей
не добавляет.

## Что заложено в конструкцию и почему

**Винты вынесены наружу уплотнительного контура.** Шесть М3 идут по фланцу за
пазом уплотнителя. Если поставить винты внутри контура, вода пойдёт внутрь по
резьбе, и уплотнитель перестанет что-либо значить.

**Паз уплотнителя — в основании, а не в крышке.** Так обе половины печатаются
без поддержек: у основания паз открыт вверх, у крышки низ ровный. При сборке
шнур лежит в пазу сам и не выпадает.

**Кнопка и световод — в торцевой стенке, а не в крышке.** Крышка прижата
к крышке контейнера кронштейном: сверху до кнопки не дотянуться.

**Фланец переходит в стенку конусом 45°.** Иначе фланец шириной 10.5 мм висел
бы в воздухе и требовал поддержек, а бобышки винтов отламывались бы по слою.

**Вставка датчика — отдельная деталь.** Головки A02YYUW и JSN-SR04T отличаются
по диаметру между партиями; перепечатать вставку — двадцать минут, корпус —
шесть часов. Прототипный HC-SR04 ставится в то же отверстие Ø30: у его вставки
два гнезда «глаз» и переходник на тот же хвостовик.

**Габарит колодок Dupont заложен в компоновку.** Провод с колодкой над
гребёнкой занимает около 6 мм — на чертеже расположения он показан пунктиром.
Это самая частая причина, по которой корпус приходится переделывать.

## Перед печатью

1. Напечатайте тестовую пластину: гнёзда Ø22.6…23.4 с шагом 0.1 мм и
   отверстия под М2/М3. Усадка у каждого принтера своя.
2. Занесите результат в `FIT_PRESS`, `FIT_SLIDE`, `FIT_FREE` в
   `model/params.py` и пересоберите.
3. Сначала печатайте `sensor_insert_*` и `button_cap` — мелочь, на которой
   видно посадку, и только потом шестичасовое основание.

Замеры пригодятся и для корпуса, и для раздела презентации о неудачных
попытках.

## Структура

```
cad/
├── build.py            сборка: STL + чертежи, с проверкой геометрии
├── requirements.txt     manifold3d, numpy
├── model/
│   ├── params.py        все размеры; правится только он
│   ├── parts.py         восемь деталей
│   ├── mockups.py       габаритные модели покупных компонентов
│   ├── solid.py         примитивы, запись STL, проверка
│   └── render.py        изометрия и чертёж расположения
├── stl/                 результат: по STL на деталь
└── render/              результат: чертежи в SVG
```
