# Схемы

Схемы генерируются кодом из той же распиновки, что описана в
[../WIRING.md](../WIRING.md):

```bash
cd hardware/schematic
python make_schematic.py        # зависимостей нет, нужен только Python 3.10+
```

| Файл | Что это |
|---|---|
| `schematic.svg` | принципиальная электрическая схема, лист 1: NodeMCU и датчик A02YYUW |
| `schematic_proto.svg` | принципиальная схема, лист 2: вариант с датчиком HC-SR04 |
| `wiring.svg` | монтажная схема: расположение деталей на макетной плате и провода |
| `netlist.csv` | список цепей в виде таблицы — для проверки прозвонкой |

Это пункт 1 задания: обвязка показана полностью — подтяжки, делители,
транзисторный ключ.

## Почему генератор, а не KiCad

Распиновка живёт в трёх местах: `firmware/include/config.h`,
`hardware/WIRING.md` и схема. Проект KiCad пришлось бы править руками при
каждой правке пинов, и рано или поздно схема разошлась бы с прошивкой. Здесь
список выводов лежит в `PINS_LEFT` / `PINS_RIGHT` в начале
`make_schematic.py`, а `netlist.csv` выгружается из того же списка `NETS`.

Если схема понадобится в KiCad (например, чтобы развести печатную плату
вместо макетной), `netlist.csv` — готовая основа: имена цепей и выводов
совпадают с обозначениями на схеме.

## Как читать

Блоки соединены **именами цепей** (`BTN`, `SENS_RX`, `LED_R`, `+5V` и так
далее), а не проводами через весь лист. Одинаковое имя = одна цепь. Так
принято в схемах любого размера: провод через половину листа читается хуже,
чем метка.

Обозначения соответствуют `../BOM.csv`:

| Позиция | Что |
|---|---|
| U1 | плата NodeMCU (ESP8266) или Wemos D1 mini |
| U2 | ультразвуковой датчик A02YYUW (UART) |
| U3 | HC-SR04 — только на листе 2 |
| J1 | разъём micro-USB на плате: питание 5 В |
| Q1 | S8050, ключ зуммера |
| D1 | светодиод RGB с общим катодом |
| SW1 | кнопка (на NodeMCU — встроенная FLASH) |
| R1…R7 | обвязка, номиналы на схеме |

Подтяжка кнопки R1 уже стоит на плате — паять её не надо, но без неё
непонятно, почему на D3 в покое высокий уровень.

## Решения, которые видно на схеме

**Датчик от 3.3 В.** При 5 В выход TX датчика был бы выше допустимого для
входа ESP8266.

**Выводы загрузчика.** D3 и D8 задают режим загрузки. Кнопка на D3 без
конденсатора, зуммер на D8 — через ключ, чтобы при включении уровни на них
были правильными.

**Делитель Echo (R6, R7).** HC-SR04 питается от 5 В и отвечает импульсом в
5 В; делитель 1 кОм / 2 кОм снижает его до 3.3 В.
