# BinSense — мониторинг заполненности мусорных контейнеров

Датчик на ESP8266 (NodeMCU) живёт под крышкой контейнера, измеряет уровень
мусора ультразвуком раз в 15 минут и отправляет данные по MQTT, когда уровень
изменился. Диспетчер видит контейнеры на карте, получает уведомления в
веб-приложении, когда пора вывозить, и может посмотреть историю
заполнения.
Питание — от USB (зарядка телефона 5 В), устройство работает постоянно.

```
  устройство (ESP8266 + УЗ-датчик)
        │ MQTT (QoS 1, retained-настройки)
        ▼
    Mosquitto ──► ingestor ──► PostgreSQL ──► Grafana (мониторинг разработчика)
                                    ▲
                                    │ SQL + LISTEN/NOTIFY
                                    ▼
                                  FastAPI ──REST/WebSocket──► веб-приложение (карта, события)
```

## Быстрый старт

```bash
git clone https://github.com/ВАША_КОМАНДА/binsense.git
cd binsense
./infra/scripts/init-env.sh bins.example.com admin@bins.example.com
docker compose up -d --build

# посмотреть, как всё работает, без единого устройства:
docker compose --profile demo up -d emulator
```

Откройте `https://bins.example.com` и войдите под администратором, пароль
напечатал `init-env.sh`. Подробная инструкция по развёртыванию —
[docs/DEPLOY.md](docs/DEPLOY.md), проверка на ноутбуке с настоящей платой по
Wi-Fi — [docs/LOCAL_TEST.md](docs/LOCAL_TEST.md).

## Возможности

**Устройство**
- ультразвуковой датчик по UART, медиана из нескольких замеров;
- питание от USB: постоянная связь с брокером, настройки применяются сразу;
- отправка только при изменении уровня или по heartbeat;
- калибровка одной кнопкой, индикация светодиодом и зуммером;
- настройка Wi-Fi через портал, учётные данные — без перепрошивки.

**Сервер**
- у каждого устройства своя учётная запись MQTT и доступ только к своим топикам;
- правила: заполнен, срочно вывезти, вывезен, нет связи, сбой датчика;
- история телеметрии с агрегацией, журнал действий;
- Grafana с техническими метриками: потери, задержки, время подключения, RSSI.

**Приложение**
- карта с цветными метками и живыми обновлениями по WebSocket;
- карточка контейнера: графики за сутки, неделю и месяц, события, настройки;
- лента событий: предупреждения всплывают на любой странице;
- добавление устройства по коду привязки (ссылкой или вручную) с выбором места на карте;
- роли: администратор, диспетчер, водитель.

## Разработка

```bash
# сервер и база в Docker, фронтенд отдельно с горячей перезагрузкой
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
cd frontend && npm install && npm run dev

# тесты
cd backend && python -m pytest
cd firmware/hosttest && ./run.sh
```
